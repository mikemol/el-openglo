# el-openglo worklist

*The worklist is the projection of the undischarged subgraph.*

## The rename

No file in the tree carries the prior mark, outside the historical records that must quote it [@MARK]; the scrub's own scan is proven able to SEE the mark, so its all-clear is a measurement rather than a blind spot [@MARK-SEES].

## The recovered tree

Every recovered generator byte-compiles [@COMPILES]; every file the archive marked partial is still recorded as partial, so a syntactically-clean file is never mistaken for a verified one [@PARTIAL]; every third-party import in the tree is accounted for in one manifest, declared or recorded as deliberately absent [@DEPS].

## The segment pipeline

Segment_topology exports the 22-segment geometry its consumers import [@ST22]; the endpoint and display-geometry helpers shipped as a separate additions file are merged into the module that owns them [@ST-ADD]; the matcher and the showcase renderer import cleanly against that geometry [@CONSUMERS] (grounded above in [@ST22]).

## The emission targets

Every emission target reads its colours from the one palette, so no target can drift from the scheme [@TOKENS]; every generator actually runs and writes its artifact, in dependency order, rather than merely compiling [@EMITTERS] (grounded above in [@COMPILES]); the browser theme emits a valid manifest for every declared variant [@CHROME] (grounded above in [@TOKENS]); text on the lit selection background clears the legibility floor in every variant [@SELECTION] (grounded above in [@EMITTERS]); the colour chain imports and solves, so the shipped schemes are solver output rather than whatever a silent fallback produced [@PALETTE-CHAIN] (grounded above in [@CONSUMERS]); the theme is rendered into a sample library, so it can be looked at rather than only described [@SAMPLES] (grounded above in [@TOKENS]); each palette role renders as its own colour, so the focus ring can be told from the body text it surrounds [@ROLES]; no generator holds a markup document as a string literal; each reads a template file that can be opened, linted and previewed on its own [@TEMPLATES] (grounded above in [@EMITTERS]); every extracted template still emits its pre-extraction baseline byte for byte, so moving an artifact to a file changed no output [@PARITY]; every segment surface renders from the one geometry substrate rather than carrying its own stroke table [@GEOMETRY] (grounded above in [@TOKENS]); the boot splash's digits are the substrate's own seven-segment projection, not a parallel table that happens to agree [@SPLASHGLYPH]; the wallpaper's ghost field registers exactly under its lit digits, rather than reading as a second display [@GHOSTREG] (grounded above in [@SAMPLES]); the rendered clock digits fit inside their bezel rather than clipping at its edge [@CLOCKFIT] (grounded above in [@SAMPLES]); every external standard this project applies is recorded with the module that applies it, and every cited applier still exists [@STANDARDS] (grounded above in [@PALETTE-CHAIN]).

## Tooling

The borrowed structural hooks pass their own selftests when run from this repo rather than the one they were written in [@HOOKS]; the structural-query hook reads a non-empty routing table of this repo's own, rather than degrading silently to a contentless refusal [@ROUTES]; the design log is read structurally rather than by eye, so its open work and its self-contradictions are computed instead of recalled [@COTYPE].

## User decisions

The decision to retire the prior mark everywhere, including descriptive prose, is recorded where a reader meets the rename [@SCOPE].
