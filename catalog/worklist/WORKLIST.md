# el-openglo worklist

*The worklist is the projection of the undischarged subgraph.*

## The rename

No file in the tree carries the prior mark, outside the historical records that must quote it [@MARK]; the scrub's own scan is proven able to SEE the mark, so its all-clear is a measurement rather than a blind spot [@MARK-SEES].

## The recovered tree

Every recovered generator byte-compiles [@COMPILES]; every file the archive marked partial is still recorded as partial, so a syntactically-clean file is never mistaken for a verified one [@PARTIAL]; every third-party import in the tree is accounted for in one manifest, declared or recorded as deliberately absent [@DEPS].

## The segment pipeline

Segment_topology exports the 22-segment geometry its consumers import [@ST22]; the endpoint and display-geometry helpers shipped as a separate additions file are merged into the module that owns them [@ST-ADD]; the matcher and the showcase renderer import cleanly against that geometry [@CONSUMERS] (grounded above in [@ST22]); the palette's constraint edges are named in one authority that the gate, the solver and the checks all read, so no two of them can disagree about which pairs are constrained [@GRAPH]; the cycle-rank measurement is proven able to distinguish a cyclic graph from a tree and to refuse an empty population, so its number is a measurement rather than an artefact of the walk [@GRAPH-SEES]; every separation pair the authority declares enforced is evaluated against the CVD floor on every variant, rather than merely being listed [@SEPARATION] (grounded above in [@GRAPH]); the separation walk is proven able to SEE a violation, so its all-clear differs from its never-having-run [@SEPARATION-SEES]; the display registry a surface receives is the emission of the Python one, restricted to the displays it instantiates, rather than a table retyped into QML [@REGISTRY]; the registry comparison is proven able to see a dropped table, a mangled one, a subset that carries the wrong displays, and a registry that disagrees with the substrate [@REGISTRY-SEES]; every palette constraint is stated as a declarative relation with a named quantity and a kind, derived from the edge authority and accepted by the symbolic solver, rather than existing only as the search that looks for it [@RELATIONS] (grounded above in [@GRAPH]); the relation check is proven to see an invented role, a floor with no bound, a relation naming no quantity, a free node nothing reaches, and an empty set, and it records what the relations do NOT determine [@RELATIONS-SEES].

## The emission targets

Every glyph in the matrix font agrees with the font it belongs to about where that font's shared features sit, so a malformed letter is caught by a check rather than only by a picture [@FONT] (grounded above in [@REGISTRY]); the marquee sample renders every glyph the font declares, so the picture can show a malformed one [@FONTSEEN] (developed below at [@SAMPLES]); the ghost is the solved balance point of its two sides rather than the best of a sampled grid, and its solve is never worse than the scan it replaces [@GHOST] (developed below at [@PALETTE-CHAIN]); the balance condition is verified as an identity and shown to fail on a deliberately unbalanced ghost, and the ceiling solve is shown to stay strictly under its threshold rather than reaching it [@GHOST-SEES]; the emitted role theme assigns palette members to a consumer's declared roles so that no other assignment over the same pool separates better, rather than merely clearing the floor [@ROLETHEME] (grounded above in [@SEPARATION]); the role-theme witness is proven to see a sub-optimal assignment and to see a colour that parses but does not reach the render, so its all-clear is a measurement [@ROLETHEME-SEES]; the ghost that renders clears the same floor the ghost that is gated does, so no contrast lives between the check and the screen [@GHOSTCOMP] (grounded above in [@GHOST], [@RELATIONS]); the composite model is verified against arithmetic endpoints and shown to catch both a ghost below its floor and one over its readability ceiling, so the red above is a measurement rather than an artefact of the model [@GHOSTCOMP-SEES]; every emission target reads its colours from the one palette, so no target can drift from the scheme [@TOKENS]; every generator actually runs and writes its artifact, in dependency order, rather than merely compiling [@EMITTERS] (grounded above in [@COMPILES]); the browser theme emits a valid manifest for every declared variant [@CHROME] (grounded above in [@TOKENS]); text on the lit selection background clears the legibility floor in every variant [@SELECTION] (grounded above in [@EMITTERS]); the colour chain imports and solves, so the shipped schemes are solver output rather than whatever a silent fallback produced [@PALETTE-CHAIN] (grounded above in [@CONSUMERS]); the theme is rendered into a sample library, so it can be looked at rather than only described [@SAMPLES] (grounded above in [@TOKENS]); each palette role renders as its own colour, so the focus ring can be told from the body text it surrounds [@ROLES]; no generator holds a markup document as a string literal; each reads a template file that can be opened, linted and previewed on its own [@TEMPLATES] (grounded above in [@EMITTERS]); every extracted template still emits its pre-extraction baseline byte for byte, so moving an artifact to a file changed no output [@PARITY]; every segment surface renders from the one geometry substrate rather than carrying its own stroke table [@GEOMETRY] (grounded above in [@TOKENS]); the boot splash's digits are the substrate's own seven-segment projection, not a parallel table that happens to agree [@SPLASHGLYPH]; the wallpaper's ghost field registers exactly under its lit digits, rather than reading as a second display [@GHOSTREG] (grounded above in [@SAMPLES]); the rendered clock digits fit inside their bezel rather than clipping at its edge [@CLOCKFIT] (grounded above in [@SAMPLES]); every external standard this project applies is recorded with the module that applies it, and every cited applier still exists [@STANDARDS] (grounded above in [@PALETTE-CHAIN]); the Gentoo overlay under overlay/ is a Portage repository whose live ebuild installs, through the same staging function the .deb wraps, a non-empty tree containing every mapped destination [@EBUILD] (grounded above in [@EMITTERS]); the palette is emitted as CSS custom properties — one block per variant, Off/Lit mapped onto prefers-color-scheme, the seen ghost stated as color-mix() — and every property equals its token [@CSS] (grounded above in [@TOKENS]); Closed design-log symbols still re-derive from the tree: every CLOSED symbol with a witness (⊕BLOOM, ⊕STROKE-WEIGHT) has its work present in the EMITTED artifacts — a closure is not a ledger line [@REGRESSIONS] (developed below at [@COTYPE]); the palette is emitted as a KDE Union style per variant — Breeze imported, its composited alphas (indicator, focus, hover) replaced by the ghost relation solved over the scheme's own colour pairs, the rest left authored and listed OPEN — and every override names a variable Breeze defines and carries its solve [@UNION] (grounded above in [@GHOST]); Every terminal format the theme ships — Konsole, Alacritty, foot, Windows Terminal, Termux — is a serialiser over ONE ansi table (make_konsole.ansi_table), parses with the parser its consumer uses, and reads back the same sixteen ANSI colours, ground and foreground [@TERMINALS] (grounded above in [@TOKENS]); the palette is emitted as a Windows .theme per variant that carries the three sections Microsoft's format requires (Desktop, VisualStyles, MasterThemeSelector MTSM=DABJDKT), the colour table as palette roles, the accent as ColorizationColor, and the wallpaper it references beside it [@WINDOWS] (grounded above in [@TOKENS]); the palette is emitted as a Firefox WebExtension theme per variant in Firefox's own theme.colors vocabulary — the two required keys present, every colour a palette role or the ghost relation solved over its pair (field borders and separators the seen ghost; hover and active fills the highlight over the toolbar at the glanced and looked-at floors), color_scheme matching the variant's polarity, a stable gecko id for AMO signing [@FIREFOX] (grounded above in [@CHROME]); Every emitter has a stated publishing route in catalog/publishing.md, and every KDE Store category id the table cites exists in the store's OCS listing cached in-tree — so no target ships without a venue and no number outlives the store's taxonomy unnoticed [@PUBLISHING] (grounded above in [@EMITTERS]).

## Tooling

The constraint netlist is emitted as a graph that renders, with every node present and every family distinguishable, and as an elimination sequence whose fill-in is drawn [@NETLISTVIEW] (grounded above in [@RELATIONS]); the render witness is proven to see a missing node, a family whose colour never reaches the output, and an empty elimination sequence [@NETLISTVIEW-SEES]; the borrowed structural hooks pass their own selftests when run from this repo rather than the one they were written in [@HOOKS]; the structural-query hook reads a non-empty routing table of this repo's own, rather than degrading silently to a contentless refusal [@ROUTES]; the design log is read structurally rather than by eye, so its open work and its self-contradictions are computed instead of recalled [@COTYPE].

## User decisions

The decision to retire the prior mark everywhere, including descriptive prose, is recorded where a reader meets the rename [@SCOPE].
