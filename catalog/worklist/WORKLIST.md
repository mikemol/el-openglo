# el-openglo worklist

*The worklist is the projection of the undischarged subgraph.*

## The rename

No file in the tree carries the prior mark, outside the historical records that must quote it [@MARK]; the scrub's own scan is proven able to SEE the mark, so its all-clear is a measurement rather than a blind spot [@MARK-SEES].

## The recovered tree

Every recovered generator byte-compiles [@COMPILES]; every file the archive marked partial is still recorded as partial, so a syntactically-clean file is never mistaken for a verified one [@PARTIAL]; every third-party import in the tree is accounted for in one manifest, declared or recorded as deliberately absent [@DEPS].

## The segment pipeline

Segment_topology exports the 22-segment geometry its consumers import [@ST22]; the endpoint and display-geometry helpers shipped as a separate additions file are merged into the module that owns them [@ST-ADD]; the matcher and the showcase renderer import cleanly against that geometry [@CONSUMERS] (grounded above in [@ST22]); the palette's constraint edges are named in one authority that the gate, the solver and the checks all read, so no two of them can disagree about which pairs are constrained [@GRAPH]; the cycle-rank measurement is proven able to distinguish a cyclic graph from a tree and to refuse an empty population, so its number is a measurement rather than an artefact of the walk [@GRAPH-SEES]; every separation pair the authority declares enforced is evaluated against the CVD floor on every variant, rather than merely being listed [@SEPARATION] (grounded above in [@GRAPH]); the separation walk is proven able to SEE a violation, so its all-clear differs from its never-having-run [@SEPARATION-SEES]; the display registry a surface receives is the emission of the Python one, restricted to the displays it instantiates, rather than a table retyped into QML [@REGISTRY]; the registry comparison is proven able to see a dropped table, a mangled one, a subset that carries the wrong displays, and a registry that disagrees with the substrate [@REGISTRY-SEES]; every palette constraint is stated as a declarative relation with a named quantity and a kind, derived from the edge authority and accepted by the symbolic solver, rather than existing only as the search that looks for it [@RELATIONS] (grounded above in [@GRAPH]); the relation check is proven to see an invented role, a floor with no bound, a relation naming no quantity, a free node nothing reaches, and an empty set, and it records what the relations do NOT determine [@RELATIONS-SEES]; the three decoration states — focus ring, selection field, hover ring — are pairwise distinguishable under the gate's own CVD-normalised metric and each clears 3:1 on its ground, on every variant, with the luminance step between them SOLVED as the smallest that satisfies the relation rather than authored [@STATES] (grounded above in [@SEPARATION]); the font-to-segment projection is cross-checked against the authored 16-seg table by a routine that reports per-glyph agreement (glyph_match.validate_projection), run over a real font on this host, and the instrument discriminates — the glyph set projects to distinct segment sets rather than one — so the agreement numbers the calibration symbol needs are measured, not recalled [@PROJECTION-VALIDATE] (grounded above in [@ST22]); a notification sender's colour reaches the phosphor as a HUE only: make_palette.rehue keeps the lit token's saturation and value at the sender's hue and returns it only if it clears the lit floor against the ground (APCA LIT_FLOOR_LC) and the gate's worst-view separation from the ghost, else the lit token itself; hue_table solves twelve buckets per variant at build time so no widget does colour arithmetic; check_rehue holds every accepted entry to both floors, every fallback to fg, and refuses a dead (all-fallback) table [@REHUE].

## The emission targets

the balance condition is verified as an identity and shown to fail on a deliberately unbalanced ghost, and the ceiling solve is shown to stay strictly under its threshold rather than reaching it [@GHOST-SEES]; the emitted role theme assigns palette members to a consumer's declared roles so that no other assignment over the same pool separates better, rather than merely clearing the floor [@ROLETHEME] (grounded above in [@SEPARATION]); the role-theme witness is proven to see a sub-optimal assignment and to see a colour that parses but does not reach the render, so its all-clear is a measurement [@ROLETHEME-SEES]; the ghost that renders clears the same floor the ghost that is gated does, so no contrast lives between the check and the screen [@GHOSTCOMP] (grounded above in [@GHOST], [@RELATIONS]); the composite model is verified against arithmetic endpoints and shown to catch both a ghost below its floor and one over its readability ceiling, so the red above is a measurement rather than an artefact of the model [@GHOSTCOMP-SEES]; every emission target reads its colours from the one palette, so no target can drift from the scheme [@TOKENS]; every generator actually runs and writes its artifact, in dependency order, into a private copy of the tracked tree; what it writes IS what is tracked (regenerate and compare), and the real tree is fingerprinted untouched across the run, so no gated check writes the files the others read (W68) [@EMITTERS] (grounded above in [@COMPILES]); the browser theme emits a valid manifest for every declared variant [@CHROME] (grounded above in [@TOKENS]); text on the lit selection background clears the legibility floor in every variant [@SELECTION] (grounded above in [@EMITTERS]); the colour chain imports and solves, so the shipped schemes are solver output rather than whatever a silent fallback produced [@PALETTE-CHAIN] (grounded above in [@CONSUMERS]); the theme is rendered into a sample library, so it can be looked at rather than only described [@SAMPLES] (grounded above in [@TOKENS]); each palette role renders as its own colour, so the focus ring can be told from the body text it surrounds [@ROLES]; no generator holds a markup document as a string literal; each reads a template file that can be opened, linted and previewed on its own [@TEMPLATES] (grounded above in [@EMITTERS]); every extracted template still emits its pre-extraction baseline byte for byte, so moving an artifact to a file changed no output [@PARITY]; every segment surface renders from the one geometry substrate rather than carrying its own stroke table [@GEOMETRY] (grounded above in [@TOKENS]); the boot splash's digits are the substrate's own seven-segment projection, not a parallel table that happens to agree [@SPLASHGLYPH]; the wallpaper's ghost field registers exactly under its lit digits, rather than reading as a second display [@GHOSTREG] (grounded above in [@SAMPLES]); the rendered clock digits fit inside their bezel rather than clipping at its edge [@CLOCKFIT] (grounded above in [@SAMPLES]); every external standard this project applies is recorded with the module that applies it, and every cited applier still exists [@STANDARDS] (grounded above in [@PALETTE-CHAIN]); the palette is emitted as CSS custom properties — one block per variant, Off/Lit mapped onto prefers-color-scheme, the seen ghost stated as color-mix() — and every property equals its token [@CSS] (grounded above in [@TOKENS]); Closed design-log symbols still re-derive from the tree: every CLOSED symbol with a witness (⊕BLOOM, ⊕STROKE-WEIGHT) has its work present in the EMITTED artifacts — a closure is not a ledger line [@REGRESSIONS] (developed below at [@COTYPE]); the palette is emitted as a KDE Union style per variant — Breeze imported, its composited alphas (indicator, focus, hover) replaced by the ghost relation solved over the scheme's own colour pairs, the rest left authored and listed OPEN — and every override names a variable Breeze defines and carries its solve [@UNION] (grounded above in [@GHOST]); Every terminal format the theme ships — Konsole, Alacritty, foot, Windows Terminal, Termux — is a serialiser over ONE ansi table (make_konsole.ansi_table), parses with the parser its consumer uses, and reads back the same sixteen ANSI colours, ground and foreground [@TERMINALS] (grounded above in [@TOKENS]); the palette is emitted as a Windows .theme per variant that carries the three sections Microsoft's format requires (Desktop, VisualStyles, MasterThemeSelector MTSM=DABJDKT), the colour table as palette roles, the accent as ColorizationColor, and the wallpaper it references beside it [@WINDOWS] (grounded above in [@TOKENS]); the palette is emitted as a Firefox WebExtension theme per variant in Firefox's own theme.colors vocabulary — the two required keys present, every colour a palette role or the ghost relation solved over its pair (field borders and separators the seen ghost; hover and active fills the highlight over the toolbar at the glanced and looked-at floors), color_scheme matching the variant's polarity, a stable gecko id for AMO signing [@FIREFOX] (grounded above in [@CHROME]); Every emitter has a stated publishing route in catalog/publishing.md, and every KDE Store category id the table cites exists in the store's OCS listing cached in-tree — so no target ships without a venue and no number outlives the store's taxonomy unnoticed [@PUBLISHING] (grounded above in [@EMITTERS]); the palette is emitted as GTK4/libadwaita CSS variables on :root and a GTK3 define-color sheet per variant — every name one the libadwaita CSS-variables reference documents, every value its palette role, the text pairs at WCAG AA and the selection pair at the palette's own floor — and a name typo is a red check, not a silent no-op [@GTK] (grounded above in [@TOKENS]); Android's own scheme derivation (material-color-utilities, TonalSpot at contrast 0), seeded from each variant's lit colour, keeps the seed's HCT hue on every variant, produces WCAG AA text pairs on every variant, and on the Off variants lands its dark surface within 5 dE of the palette's ground — the Lit variants' backlit ground is unreachable by Monet's near-white light surface and is recorded as such in catalog/android.md, not claimed [@MONET] (grounded above in [@TOKENS]); Notification bodies are markup (the freedesktop spec allows b i u a img; Plasma passes its sanitised subset with br and entities) and the marquee scrolls their TEXT: templates/marquee-body.js parses a body to plain text plus style runs, shipped beside the plasmoid and run headless by check_marquee_body under Qt's qml runner on synthetic bodies — a surviving tag, a wrong run span or an encoded entity fails; withheld without the qml runner [@MARQUEE-LIVE]; Every id the per-variant builds ever wrote into a user's containments (org.el.openglo.live.<v>, org.el.segclock.<v>, org.el.notifymarquee.<v>) still ships as a thin copy of the one package (the same bound QML), so an appletsrc naming a legacy id loads - a missing WALLPAPER plugin fails the whole shell (operator, 2026-09-22) - and the shipped one-shot Plasma update script (contents/updates/el-openglo-one-theme.js) moves a desktop's wallpaper plugin and each legacy applet to the one ids with its settings and place kept; ## Tooling

The constraint netlist is emitted as a graph that renders, with every node present and every family distinguishable, and as an elimination sequence whose fill-in is drawn [@NETLISTVIEW] (grounded above in [@RELATIONS]); the render witness is proven to see a missing node, a family whose colour never reaches the output, and an empty elimination sequence [@NETLISTVIEW-SEES]; the borrowed structural hooks pass their own selftests when run from this repo rather than the one they were written in [@HOOKS]; the structural-query hook reads a non-empty routing table of this repo's own, rather than degrading silently to a contentless refusal [@ROUTES]; the design log is read structurally rather than by eye, so its open work and its self-contradictions are computed instead of recalled [@COTYPE]; Every emitted QML document (nine: clock, marquee and its components, live wallpaper, switcher, configs) passes qmllint's error set, and no finite animation binds running: (a finite run assigns running=false when it ends, discarding the binding - the marquee's dead-after-first-drain defect, live 2026-09-22) [@QMLLINT]; Every requirement written as a rego policy (policy/NAME.rego, package el.NAME, deny + withheld sets, an empty-population deny first) has a refusing and an admitting test in policy/NAME_test.rego, and opa test policy/ passes; a policy answers to its name and its check has a --json measurement [@REGO]; Every surface x variant is rendered through the theme to a checked-in still that exists, is not blank and sits on its variant's ground; and the marquee scrolls in a checked-in APNG per variant whose every frame is the previous one shifted left — never a tear (S0-S5) [@SCREENS]; a committed artifact is CURRENT: built from the inputs that are in the tree now, not from inputs that have since changed. The operator reported grid glitching in a checked-in screen; it was fixed, the fix was proven, and the commit captured the PRE-FIX picture because the 48-render sweep had not finished. Currency is a THIRD obligation neither boundary of the build graph sees -- build_graph asks PRODUCED and CONSUMED, and a file can be both and still be wrong. check_action_key digests each action's declared domain (its entry module's exact import closure, its data DIRECTORIES rather than files, and its HOST inputs) and compares it against the key recorded when the outputs were built. A host input is declared, not excused: there is no uncacheable action, only an undeclared one [@CURRENCY]; Every Qt-tool spawn in the tree (qml, qmllint and kin, resolved from its argv rather than matched by spelling) goes through qt_sandbox, so no render or lint reaches the live session, its GPU driver or KCrash (W73) [@QT-SANDBOX].
